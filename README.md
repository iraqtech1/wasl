# واصل — واجهة Vue للتاجر والمندوب

التطبيق الحالي فرونت إند مستقل باستخدام Vue 3 وVite، يعمل مباشرة على GitHub Pages بدون خادم API. الهوية البصرية والألوان وشعار واصل محفوظة.

## التشغيل

يتطلب Node.js 24 أو أحدث وpnpm.

```sh
pnpm install
pnpm dev
```

لنسخة الإنتاج المحلية: `pnpm start` يبني الواجهة ويعرضها على http://localhost:4173/ .

## الصفحات والبيانات

اختَر التاجر أو المندوب ثم زر «تسجيل الدخول» مباشرة دون تعبئة الحقول. تتوفر صفحات الرئيسية والطلبات والمحفظة والحساب، وإنشاء الطلب للتاجر والطلبات المتاحة للمندوب، إضافة إلى التسجيل. الروابط بصيغة `#/merchant/wallet` تدعم فتح الصفحة مباشرة والتحديث والرجوع.

الطلبات والحسابات والمحادثات والتقييمات والحركات محاكاة محلية لأغراض تجربة الواجهة؛ تحفظ تغييراتها في localStorage داخل المتصفح نفسه، ولا تتشارك البيانات بين الأجهزة. كلمات المرور وصور المستمسكات لا تحفظ ضمن البيانات التجريبية. تعديل الملف متاح في هذه المرحلة.

## PWA

يتوفر زر تثبيت التطبيق مع إرشادات للمتصفحات التي لا تتيح نافذة التثبيت. يحتاج التثبيت HTTPS أو localhost. يخزن Service Worker الأصول للاستخدام دون اتصال بعد أول زيارة، وتبقى الإجراءات التجريبية محلية. يتولد إصدار التخزين تلقائيًا عند البناء؛ لا تعدل `sw.js` الناتج يدويًا.

## بنية Vue والربط لاحقًا

- `src/App.vue`: هيكل التطبيق والتنقل والنوافذ والسبلاش.
- `src/renderers/`: مكونات الشاشات بدوال Vue render، دون حقن HTML.
- `src/composables/useWasel.js`: الحالة التفاعلية وإجراءات المستخدم.
- `src/services/api.js`: نقطة استبدال محاكاة البيانات باتصال الخادم لاحقًا.
- `src/services/demoApi.js` و`demoData.js`: الإجراءات والبيانات التجريبية المحلية.
- `src/services/routes.js`: مسارات الصفحات.
- `web/index.html`: مصدر صفحة الدخول؛ ملفات CSS والشعار وخط كايرو محفوظة.

ملفات الخادم السابقة `server.cjs` و`domain.cjs` باقية للاستفادة منها لاحقًا، لكنها لا تعمل ضمن نسخة Pages ولا يحتاجها تشغيل الواجهة. يمكن فحصها منفصلة عبر `pnpm test:server`.

## الفحص والنشر

```sh
pnpm build
pnpm test
pnpm check
pnpm build:pages
```

الاختبارات تشمل مكونات Vue للدورين، مسارات التنقل، دورة الطلب التجريبية وحفظها، التسجيل وحماية النصوص، المحفظة وPWA. نشر التعديلات موضح في [GITHUB-UPLOAD.md](GITHUB-UPLOAD.md).

## إعدادات الحساب والمظهر

أسفل «حسابي» توجد خيارات تسجيل الخروج والخصوصية والشروط وحول التطبيق والوضع الليلي. يستطيع الزائر فتحها من زر الإعدادات، ويظهر له تسجيل الدخول بدل الخروج. تظهر شركة عراق تكنو للحلول البرمجية باعتبارها مطوّر المشروع.

الوضع الليلي يشمل شاشات الدخول والتسجيل والطلبات والمحفظة والنوافذ. يتبع تفضيل الجهاز أول مرة، ويحفظ الاختيار اليدوي محليًا. عدّاد الجرس يعرض غير المقروء، وتُحفظ حالة القراءة لكل حساب على الجهاز. تغيّرات الطلبات ورسائل المحادثة تولّد إشعارات تجريبية محلية؛ ليست إشعارات Push عبر خادم.
