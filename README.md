# واصل — التاجر والمندوب

نسخة النظام بدورين فقط: التاجر والمندوب، مرتبطة بخادم Node.js وقاعدة SQLite.

## التشغيل

يتطلب Node.js 24 أو أحدث. الواجهة أصبحت Vue 3 مع Vite. ثبّت الحزم وابنِ الواجهة قبل تشغيل الخادم:

```sh
node server.cjs
```

افتح http://localhost:4173/ . يدعم الخادم `/merchant/` و`/courier/`، وتبدأ الصفحة بسبلاش مدته ثلاث ثوانٍ ثم اختيار الدور بكارتين زجاجيين، ثم نموذج الدخول الخاص بالدور المختار. تقليل الحركة في الجهاز يقلل مدة السبلاش ويوقف حركته.

## تثبيت التطبيق (PWA)

التطبيق PWA كامل: `manifest.webmanifest` لكل دور، و`sw.js` يخزّن الواجهة والأصول للعمل دون اتصال، وزر «تثبيت التطبيق» في الصفحة الرئيسية يستدعي محرّك التثبيت حين يتوفر.

- التثبيت الفعلي عبر HTTPS؛ على `http://localhost` يسمح به المتصفح، أما من عنوان الشبكة المحلية فلا.
- الأيقونات تُولَّد من صورة الهوية عبر `tools/make-icons.ps1`، ومواصفاتها في [BRAND.md](BRAND.md).
- عند تغيير أي أصل مخزّن، ارفع رقم `CACHE` في `sw.js` ليفتح المتصفح النسخة الجديدة.

المتغيرات: `WASEL_DATA_DIR` لمجلد البيانات، `PORT` لرقم منفذ الشبكة، و`HOST` لعنوان الاستماع (الافتراضي 127.0.0.1). يتيح `TRUST_LOCAL_PROXY=1` التعامل مع HTTPS المحوّل من وكيل محلي على loopback فقط.

## السلوك الحالي

- التسجيل الجديد يصبح فعالاً مباشرة في النسخة التجريبية بعد استكمال البيانات.
- تعديل الملف يُحفظ مباشرة، مع استمرار منعه أثناء الطلبات والتسويات المفتوحة وثبات معرف الحساب والمحفظة.
- دورة الطلبات، الحجز والاستلام والتوصيل والمرتجعات والمحادثات والتقييمات مستمرة.
- المحفظة تعرض الرصيد والحركات المسجلة وتصميم زجاجي بحلقة حول الرصيد. لا توجد خدمة شحن أو سحب في النسخة الحالية.
- ضوابط التشغيل الأساسية داخل `domain.cjs`؛ لا توجد واجهة لإدارة النظام.
- تم حذف الدورين السابقين ومساراتهما وواجهاتهما وعمليات الشحن والاعتماد والدعم المرتبطة بهما. تنفذ ترقية قاعدة البيانات مرة واحدة، مع الاحتفاظ بأرصدة المستخدمين الباقين والطلبات.

## الاختبارات

```sh
pnpm test
```

تعمل اختبارات الصلاحيات ودورة الطلبات على قاعدة مؤقتة مستقلة. تستخدم الجلسات ملفات تعريف ارتباط HttpOnly وكلمات المرور scrypt.

## حدود النسخة

التطبيق تجريبي؛ لا يوجد دفع مصرفي أو SMS/OTP أو Push في الخلفية. GPS يعمل أثناء فتح التطبيق. تثبيت PWA يحتاج HTTPS؛ تُخزّن الواجهة والأصول محلياً، والدخول الجديد والإجراءات المشتركة يحتاجان اتصالاً بالخادم. لا تُضمّن قواعد بيانات التشغيل في ملف توزيع الكود.



## مبالغ المحفظة التجريبية
لتعبئة الحسابين التجريبيين فقط بحركات إضافات وخصومات بعد بدء قاعدة البيانات، شغّل: node seed-demo-wallet.cjs مع نفس WASEL_DATA_DIR. إعادة التشغيل لا تكرر الحركات. رصيد التاجر النموذجي 162,500 د.ع ورصيد المندوب 101,500 د.ع، قبل أي حركات إضافية. هذه قيود تجريبية لا تمثل أموالاً حقيقية.

## تسجيل حساب المندوب
واجهة زجاجية بألوان واصل وخط كايرو، تتضمن بيانات المندوب وتأكيد كلمة المرور واختيار المركبة، وبطاقة السكن والبطاقة الوطنية وإجازة السوق (الأمام والخلف للأخيرتين). تدعم اختيار الصور أو تصويرها بالكاميرا مع معاينة وإعادة التصوير، ثم مراجعة البيانات قبل إنشاء الحساب. الكاميرا تحتاج HTTPS وإذن المستخدم. الصور محفوظة ضمن الملف الخاص ولا تُرجع ضمن بيانات الدخول أو الحالة العامة. فُحص تصميم نافذة التصوير على الموبايل؛ التصوير الفعلي يحتاج تجربة المستخدم على جهازه.

## بنية Vue 3

- `src/App.vue`: هيكل التطبيق، التنقل، النوافذ، السبلاش والتنبيهات.
- `src/components/`: مكوّنات التثبيت والنوافذ المشتركة.
- `src/composables/useWasel.js`: حالة الواجهة التفاعلية، إجراءات المستخدم، API والكاميرا، مع تنظيف الموارد عند مغادرة المكوّن.
- `src/renderers/`: مكوّنات العرض بدوال Vue render functions للطلبات والحساب والمحفظة والتسجيل، دون حقن HTML أو تشغيل الملفات القديمة.
- `web/index.html`: مدخل الواجهة المصدرية. ملفات CSS الأصلية والشعار وخط كايرو محفوظة.
- `server.cjs` و`domain.cjs`: خادم Node.js وقواعد العمل وقاعدة SQLite، وتبقى بيانات `data/` محلية.

للتطوير شغّل الخادم في نافذة، و`pnpm dev` في نافذة أخرى. Vite يمرر API إلى `http://127.0.0.1:4173`؛ يمكن تغيير ذلك عبر `WASEL_API_URL`.

`pnpm build` يولّد `dist/` للخادم. `pnpm build:pages` يولّد `site/` وينسخ ملفات النشر إلى جذر المستودع لأن GitHub Pages الحالي ينشر `main / root`. ارفع الملفات الناتجة مع تغييرات المصدر. لا تعدّل `index.html` المنشور يدويًا؛ عدّل `web/index.html` ثم ابنِ مجددًا. الملفات ذات الأسماء المحتوية على بصمة تتغير تلقائيًا، وService Worker يطلب النسخة الجديدة عند التحديث مع نسخة احتياطية عند فقد الاتصال.

GitHub Pages يبقى معاينة قابلة للتثبيت. تسجيل الحسابات والطلبات يتطلب تشغيل خادم Node.js؛ تحويل الواجهة إلى Vue لا يغيّر هذا القيد.

الفحص: `pnpm build && pnpm test && pnpm check`. يشمل قواعد العمل، شاشات Vue للدورين، خطوات التسجيل والطلبات، نماذج إجراءات الطلب، سلامة عرض النصوص، والمحفظة وPWA.
